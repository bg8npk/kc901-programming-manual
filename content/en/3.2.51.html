3.2.51 Frequency-List S12 Enhanced Response Calibration (Fourth-Generation KC901X)

3.2.51 Frequency-List S12 Enhanced Response Calibration (Fourth-Generation KC901X) — reference table

Send command

Option

Description

list_enresponse_s12_cal

None

Perform S12 enhanced response calibration using the frequency list.

Description:

This command starts an interactive enhanced response calibration at the frequencies in the custom list, over the serial or Ethernet connection. When sweeping the frequency list with S12 enhanced response calibration selected, this calibration data is used by default. If the frequency range exceeds the calibrated range, system calibration is used instead. The procedure involves several exchanges. Host software only needs to identify packet header names; matching the message text is unnecessary.

$list_enresponse_s12_cal\n
$start,s12_Cal_confirm\n
$******S12 Enhance Response calibration******\n
$Do you want to calibrate the device?[Yes/no]\n
$end\n
$yes\n
$start,s12_enhance_response_cal_wait\n
$ waiting for the circuit to be stability...\n
$end\n
$start,port_polarity\n
$Enter female or male to specify the polarity of the PORT2:\n
$end\n
$female\n
$start,cal_open\n
$Step 1:Please connect the OPEN module to PORT2 then send 'yes'.\n
$end\n
$yes\n
$start,cal_short\n
$Step 2:Please connect the SHORT module to PORT2 then send 'yes'.\n
$end\n
$yes\n
$start,cal_load\n
$Step 3:Please connect the LOAD module to PORT2 then send 'yes'.\n
$end\n
$yes\n
$start,port_polarity\n
$Enter female,male or f_m to specify the polarity of the PORTS:\n
$end\n
$female\n
$start,cal_connect\n
$Step 4:Please connect PORT1 and PORT2 then send 'yes'.\n
$end\n
$yes\n
$start,cal_completed\n
$Calibration completed!\n
$end\n

While the instrument is waiting for confirmation from the host, the user can enter 'exit\n' to leave calibration mode, as shown below:

$exit\n
$start,exit\n
$Exit calibration\n
$end\n
