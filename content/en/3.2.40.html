3.2.40 Valid Source Amplitude Range at Specified Frequencies (Fourth-Generation KC901X)

3.2.40 Valid Source Amplitude Range at Specified Frequencies (Fourth-Generation KC901X) — reference table

Send command

Option

Parameter

Description

range_source_level

get

start freq

stop freq

point

Query the valid signal source amplitude range at specified frequencies.

Description:

Provide the start frequency, stop frequency, and number of points. The instrument returns the valid signal source amplitude range for those frequencies.

Example:

$range_source_level,get,100000000,200000000,201\n
$start,range_source_level,get,success\n
$-43,9\n
$end\n
