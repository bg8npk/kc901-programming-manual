1.2 Response Format

The response format differs slightly from the command format to make it easier for the host to identify the data. In the examples, a semicolon ";" and the rest of that line indicate a comment.

$start,[packet_name]\n  ; Each line starts with "$" and ends with "\n". "start" marks the beginning.
$[packet_contents]\n        ; Packet elements are separated by commas ",".
$end\n             ; "end" marks the end of the packet.
