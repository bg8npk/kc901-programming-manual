Description:

Options:

init -> Initialize S11. Required before using S11.

run -> Run an S11 frequency sweep and acquire data.

stop -> Stop and close S11. Required before switching to another operating mode.

Parameter 1:

s11cal -> Enable S11 calibration.

full2portcal -> Enable full two-port calibration.

syscal -> Enable system calibration.

caloff -> Disable system calibration.

Parameter 2:

ri -> Return real and imaginary components.

ma -> Return reflection coefficient magnitude and phase angle.

vswr -> Return voltage standing wave ratio.

z -> Return impedance.

loss -> Return return loss (logarithmic value).

Parameter 3 sets the number of sweep points. Fourth-generation KC901 instruments support up to 10000 points. To sweep more than 10000 points, use multiple S11 commands to sweep separate segments.

A single measurement point is allowed. In this case, measurement continues and the instrument continuously sends results at that frequency to the host.

Parameter 4:

cs -> Specify the sweep range using cent and span.

ss -> Specify the sweep range using start and stop.

If parameter 3 specifies a single frequency point, parameter 4 can be cs or ss. Only parameter 5 is required (cent or start); parameter 6 would be parsed as a new command by the KC901.

Parameters 5 and 6 specify center frequency and span (cs), or start and stop frequencies (ss), in Hz. Use the format selected by parameter 4.

The available frequency range depends on the instrument and is the same as the range available during local operation. Examples follow:

7. Example:

When the number of sweep points is greater than 1:

$s11,run,caloff,ri,2,cs,100000000,50000000\n
$start,s11,ri\n
75000000,-4.1824e-01,-2.1633e-01\n  ; Frequency, real component, imaginary component.
125000000,-1.1707e,3.3581e-01\n
$end\n
$s11,run,caloff,ma,2,cs,100000000,50000000\n
$start,s11,ma\n
75000000,5.8471e-01,-26.4973\n ; Frequency, reflection coefficient magnitude, phase.
125000000,5.9342e-01,-51.8204\n
$end\n
$s11,run,caloff,vswr,2,cs,100000000,50000000\n
$start,s11,vswr\n
75000000,1.4256\n           ; Frequency, voltage standing wave ratio.
125000000,1.1521\n
$end\n
$s11,run,caloff,z,2,cs,100000000,50000000\n
$start,s11,z\n; Frequency, impedance magnitude, resistance, reactance.
75000000,137.9871,109.6309,-83.7945\n
125000000,91.2070,52.7077,-74.4354\n
$end\n
$s11,run,caloff,loss,2,cs,100000000,50000000\n
$start,s11,loss\n
75000000,-0.4092\n; Frequency, return loss.
125000000,-0.5743\n
$end

When the number of sweep points is 1:

S11 performs repeated acquisition, with each acquisition returned in a separate packet, as shown below:

$s11,run,caloff,loss,1,cs,100000000\n
$start,s11,loss\n
100000000,-8.9216\n
$end\n
$start,s11,loss\n
100000000,-25.9223\n
$end\n
$start,s11,loss\n
100000000,-25.7827\n
$end\n
$start,s11,loss\n
100000000,-25.6808\n
$end\n
