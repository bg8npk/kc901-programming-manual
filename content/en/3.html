3. Command Reference

This section describes the KC901 commands and provides practical examples. Observe the following conventions:

1. Purple indicates host transmissions; blue indicates instrument responses.

2. The line terminator "\n" is shown explicitly in transmitted and returned data. It is not visible as literal text in actual responses.

3. Separate commands, options, and parameters with commas.

4. A semicolon ";" and the remainder of the line indicate a comment and are not part of the actual protocol data.
