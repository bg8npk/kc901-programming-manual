3.2.5 Output Attenuation

3.2.5 Output Attenuation — reference table

Command

Option

Description

outAtt

None

get (fourth-generation KC901X only)

set (fourth-generation KC901X only)

Parameter range:

KC901K、J、R :-30~30

KC901V/RFMA : 0~25

KC901S+ :0~20

Unit: dB

This output attenuation applies in the following modes:

S11 (reflection),

S21 (transmission),

S22 (reflection; fourth-generation KC901X only),

S12 (transmission; fourth-generation KC901X only),

DTF (distance to fault),

On fourth-generation KC901 instruments, this setting places the output amplitude in source gain mode.

Example:

Third-generation KC901X:

Set the output attenuator to 10dB attenuation.

$outAtt,10\n

Fourth-generation KC901X:

Set the output attenuator to 10dB attenuation.

$outAtt,set,10\n
$start,OutAtt,set,success\n
$end\n

Query the current output attenuation.

$outAtt,get\n
$start,OutAtt,get,success\n
$10\n
$end\n
