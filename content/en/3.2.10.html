3.2.10 S11 System Calibration Standard Parameters (Fourth-Generation KC901X; unavailable in firmware version 1.8.0 and later)

KC901K/RFMA uses the standard calibration model:

3.2.10 S11 System Calibration Standard Parameters (Fourth-Generation KC901X; unavailable in firmware version 1.8.0 and later) — reference table

Command

Option

Description

kit_s11

female

male

Enter the short and open standard parameters, in that order.

The short standard parameters are, in order:

L0,L1,L2,L3, one-way electrical length (mm), total loss (GΩ/m)

The open standard parameters are, in order:

C0,C1,C2,C3, one-way electrical length (mm), total loss (GΩ/m)

Range:

L0-L3 and C0-C3: -9999.999 to +9999.999. The exponents are the same as those displayed in the instrument's calibration standard settings and do not need to be specified.

One-way electrical length: 0-999.999

Total loss: 0-9999.999

These are the calibration standard settings for system calibration. On the instrument, open Settings and press [SHIFT]+[7] to enter the system calibration screen. These are not the user calibration standard settings on the main Settings screen.

Description:

Use female for female calibration standards and male for male calibration standards. Third-generation KC901X instruments do not have the female and male options.

Example:

Set the electrical lengths of the short and open standards to 5.25mm and 5.26mm, respectively. The load standard has no electrical length setting.

// L0,L1 , L2,L3,mm,GΩ/m C0, C1, C2, C3, mm, GΩ/m

Fourth-generation KC901X example:

$kit_s11,female,10,125,-20,15,5.25,0.201,100,125,-800,15,5.26,0.200\n

Third-generation KC901X example:

$kit_s11,10,125,-20,15,5.25,0.201,100,125,-800,15,5.26,0.200\n
