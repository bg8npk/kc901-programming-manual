Description:

1. Options:

init -> Initialize S22. Required before using S22.

run -> Run an S22 frequency sweep and acquire data.

stop -> Stop and close S22. Required before switching to another operating mode.

2. Parameter 1:

s22cal -> Enable S22 calibration.

full2portcal -> Enable full two-port calibration.

syscal -> Enable system calibration.

caloff -> Disable system calibration.

3. Parameter 2:

ri -> Return real and imaginary components.

ma -> Return reflection coefficient magnitude and phase angle.

vswr -> Return voltage standing wave ratio.

z -> Return impedance.

loss -> Return return loss (logarithmic value).

4. Example:

$sweep_list_s22,run,caloff,ri\n
$start,s22,ri\n

40000000,-2.8701e+00,-1.6338e+00\n
$end\n
