Description:

1. Options:

init -> Initialize FIELD. Required before using FIELD.

run -> Run FIELD and acquire measurement data.

stop -> Stop and close FIELD. Required before switching to another operating mode.

2. Parameter 1:

lowlo -> Measure using the low local-oscillator setting.

highlo -> Measure using the high local-oscillator setting.

3. Parameter 3: Antenna gain, in dBi.

Antenna gain range: -100.00 to +100.00dBi.

4. Parameter 4: Single-point measurement frequency in Hz, with resolution down to 0.1Hz.

The available frequency range depends on the instrument, as shown in the following table:

5. Parameter 5:

port1 -> Select input port 1 (PORT1).

port2 -> Select input port 2 (PORT2).

6. Parameter 6:

single -> Single acquisition.

continue -> Repeated acquisition.

7. Example:

With parameter 6 set to single, field strength is acquired once and only one packet is received, for example:

$field,run,lowlo,10,100000000,port1,single\n
$start,field\n
100000000,28.792,-78.438 \n    ; Frequency, field strength, absolute level (dBm).
$end\n

With parameter 6 set to continue, field strength is acquired repeatedly and data is received continuously, for example:

$field,run,lowlo,10,100000000,port1, continue\n
$start,field\n
100000000,22.297,-84.933\n   ; Frequency, field strength, absolute level (dBm).
$end\n
$start,field\n
100000000,21.680,-85.550\n
$end\n
$start,field\n
100000000,30.598,-76.632\n
$end\n
$start,field\n
100000000,30.598,-76.632\n
$end\n
