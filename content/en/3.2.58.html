3.2.58 Kit File Commands (Fourth-Generation KC901X)

The following commands manage Kit files stored in fourth-generation 901X instruments. Commands start with $ and end with a newline \n; parameters are separated by commas. Kit file names must include the .kit suffix. The instrument can store up to 21 Kit files, including default.kit.

kit_file_list gets all Kit file names stored in the instrument. File names are returned in the instrument's current list order.

$kit_file_list\n
$start,kit_file_list\n
default.kit\n
N_Kit_01.kit\n
N_Kit_02.kit\n
$end\n

kit_file_edit adds, deletes, or renames Kit files. Adding a file copies the calibration-kit parameters from default.kit. The default.kit file cannot be deleted. The operation fails if the file already exists, the file count limit is reached, the file name is invalid, or the Flash save fails.

$kit_file_edit,add,N_Kit_01.kit\n
$start,kit_file_edit,add,success\n
$end\n
$kit_file_edit,delete,N_Kit_01.kit\n
$start,kit_file_edit,delete,success\n
$end\n
$kit_file_edit,rename,N_Kit_01.kit,N_Kit_02.kit\n
$start,kit_file_edit,rename,success\n
$end\n

On failure, the command returns fail for the corresponding option, for example:

$start,kit_file_edit,add,fail\n
$end\n

kit_file_select sets or queries the Kit file used for host calibration. The selection is not written to Flash; after the instrument restarts, default.kit is selected by default. Set the required Kit file before running host calibration commands.

$kit_file_select,set,N_Kit_01.kit\n
$start,kit_file_select,set,success\n
$N_Kit_01.kit\n
$end\n
$kit_file_select,get\n
$start,kit_file_select,get,success\n
$N_Kit_01.kit\n
$end\n

If the selected file does not exist, the instrument returns:

$start,kit_file_select,set,error\n
$end\n

kit_file_param reads or modifies calibration-kit parameters in the specified Kit file. The parameter order is fixed:

If the command, option, or parameters cannot be parsed, the instrument may return error frames such as err_cmd, err_opt, err_par1, and err_par2. Example:

$start,err_cmd\n
$error:Command input error!\n
$end\n
