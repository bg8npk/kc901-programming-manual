Description:

This command starts an interactive SOL calibration over the serial or Ethernet connection. When S11 user calibration is selected during subsequent operation, this calibration data is used by default. If the frequency range exceeds the calibrated range, system calibration is used instead. The procedure involves several exchanges. Host software only needs to identify packet header names; matching the message text is unnecessary.

$cal_user_s11,10,cs,901000000,10000000\n
$start,s11_Cal_confirm\n
$******S11 calibration******\n
$Do you want to calibrate the device?[Yes/no]\n
$end
$yes\n
$start,s11_cal_wait\n
$ waiting for the circuit to be stability...\n
$end\n
$start,port_polarity\n
$Enter female or male to specify the polarity of the PORT1:\n
$end\n
$female\n
$start,cal_open\n
$Step 1:Please connect the OPEN module to PORT1 then send 'yes'.\n
$end\n
$yes\n
$start,cal_short\n
$Step 2:Please connect the SHORT module to PORT1 then send 'yes'.\n
$end\n
$yes\n
$start,cal_load\n
$Step 3:Please connect the LOAD module to PORT1 then send 'yes'.\n
$end\n
$yes\n
$start,cal_completed\n
$Calibration completed!\n
$end\n

While the instrument is waiting for confirmation from the host, the user can enter 'exit\n' to leave calibration mode, as shown below:

$exit\n
$start,exit\n
$Exit calibration\n
$end\n
