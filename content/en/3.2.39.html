3.2.39 Signal Source Amplitude (Fourth-Generation KC901X) — reference table

Send command

Option

Parameter

Description

source_level

get

set

level

Operate the instrument in level mode.

Description:

The set option sets the signal source output amplitude and places the instrument in level mode.

The get option takes no parameters and returns the signal source amplitude for level mode.

Example:

$source_level,set,-50\n
$start,source_level,set,success\n
$end\n
$source_level,get\n
$start,source_level,get,success\n
$-50\n
$end\n
