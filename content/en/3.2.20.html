3.2.20 Network Parameters

3.2.20 Network Parameters — reference table

Command

Option

Description

netinfo

None

Read the current network settings.

ip

None

Device address

gw

None

Gateway address

msk

None

Subnet mask

port

None

Port number (less than 65535)

Example:

Read the current network settings:

$netinfo\n
$start,NetInfo\n
dhcp: on\n; DHCP status
192,168,1,2\n                 ; IP address
192,168,1,1\n                 ; Gateway address
255,255,255,0\n               ; Subnet mask
901\n                       ; Port number
$end\n

Set the IP address:

$ip,192.168.1.2\n

Set the gateway address:

$gw,192.168.1.1\n

Set the subnet mask:

$msk,255.255.255.0\n

Set the port number. Only third-generation KC901X instruments allow the port number to be changed. On fourth-generation instruments, it is fixed at 901.

$port,901\n
