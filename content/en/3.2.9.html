3.2.9 S11 Cable Compensation

3.2.9 S11 Cable Compensation — reference table

Command

Option

Description

cable

len

Cable length in meters. Range: 0-99.999.

loss

Cable attenuation in dB. Range: 0-99.99.

freq

Frequency at which the cable attenuation is specified, in MHz. Range: 1-10000.

Example:

Set the cable length compensation to 10.123 meters.

$cable,len,10.123\n
