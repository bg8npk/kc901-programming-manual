Description:

1. Options:

init -> Initialize S12. Required before using S12.

run -> Run an S12 frequency sweep and acquire data.

stop -> Stop and close S12. Required before switching to another operating mode.

2. Parameter 1:

rescal -> Enable response calibration.

resisocal -> Enable response and isolation calibration.

enrescal -> Enable enhanced response calibration.

full2portcal -> Enable full two-port calibration.

syscal -> Enable system calibration.

caloff -> Disable system calibration.

3. Parameter 2:

ri -> Return real and imaginary components.

ma -> Return insertion loss and phase.

vswr -> Return voltage standing wave ratio.

series_z -> Return z, r, x for series impedance.

loss -> Return insertion loss (logarithmic value).

parallel_z -> Return z, r, x for parallel impedance.

4. Parameter 3:

lowlo -> Sweep using the low local-oscillator setting.

highlo -> Sweep using the high local-oscillator setting.

Example:

$sweep_list_s12,run,caloff,ri,lowlo\n

$end\n
