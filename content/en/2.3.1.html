2.3.1 Enabling the Network Interface

Before connecting to a network, press FUNC to open Settings and set the Network submenu to ON. Fourth-generation KC901 instruments do not have this setting; connecting an Ethernet cable enables the interface automatically. The yellow Ethernet indicator lights when networking is enabled. Because networking consumes additional power, disable it when not in use. On fourth-generation KC901 instruments, the Ethernet interface cannot be powered off manually; unplugging the cable puts it to sleep automatically.
