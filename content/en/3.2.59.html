3.2.59 Remote Mode Setting (Fourth-Generation KC901X)

This command queries or sets the dedicated remote interface, corresponding to the instrument Remote Mode setting.

Note: remote_mode on/off only switches the instrument display and saves that interface setting. It does not disconnect the current remote connection or release host control. Even when set to off, the host can continue sending commands over the existing connection.

3.2.59 Remote Mode Setting (Fourth-Generation KC901X)
CommandOptionParameterDescription
remote_modeget—Query the remote mode setting; returns $on or $off. This is not the connection state. A newly set value is reported even if the page transition is still pending.
remote_modesetonEnable remote mode and immediately save the setting to Flash.
remote_modesetoffDisable remote mode and immediately save the setting to Flash.

Query (enabled in this example)

$remote_mode,get\n
$start,remote,get,success\n
$on\n
$end\n

Enable

$remote_mode,set,on\n
$start,remote,set,success\n
$end\n

Disable

$remote_mode,set,off\n
$start,remote,set,success\n
$end\n

When remote_mode,set,off is sent from the dedicated remote interface, the remote connection remains active. The instrument clears the screen and displays the “Operation by host computer” dialog instead of immediately returning to the previous measurement mode. Press SHIFT+HOME to disconnect the remote connection and release host control, then return to the previous measurement mode.
