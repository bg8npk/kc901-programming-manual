3.2.17 Operating Time Statistics

3.2.17 Operating Time Statistics — reference table

Send command

Option

Data description

times

None

Returns the power-on count, current session duration, and total operating time, in that order.

Example:

Read the operating time statistics.

$times\n
$start,times\n
$1223,2,52,51,2,2,52,51\n  ; Power-on count, session duration (hours, minutes, seconds),
; Total operating time (days, hours, minutes, seconds).
$end\n
