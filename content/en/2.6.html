2.6 Stopping Data Output

To stop an operation while the KC901 is returning continuous data, send [Ctrl]+[C] from the host (hexadecimal 0x03). The KC901 stops executing the commands it has received, finishes transmitting all data already measured but not yet fully sent, and then stops returning data.

Note:

1. After data output is stopped, the KC901 returns fully to its initial state. For example, if [Ctrl]+[C] is sent while acquiring data with s11 RUN, send s11 init again before running s11 run.

2. When using SecureCRT, first click the data display window, then press [Ctrl]+[C].
