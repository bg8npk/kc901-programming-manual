Description:

1. Options:

init -> Initialize SPEC. Required before using SPEC.

run -> Run a SPEC frequency sweep and acquire data.

stop -> Stop and close SPEC. Required before switching to another operating mode.

2. Parameter 1:

calon -> Enable system calibration.

caloff -> Disable system calibration.

3. Parameter 2:

lowlo -> Sweep using the low local-oscillator setting.

highlo -> Sweep using the high local-oscillator setting.

Parameter 3 sets the number of sweep points. Fourth-generation KC901 instruments support up to 10000 points. For more points, use this command multiple times. To measure a single frequency, set the point count to 1. Unlike field strength mode, this mode allows a reference level to be specified. Specifying a reference level is recommended when measuring relative values accurately.

5. Parameter 4:

cs -> Specify the sweep range using Cent and Span.

ss -> Specify the sweep range using Start and Stop.

If parameter 3 specifies a single frequency point, set parameter 4 to CS.

Parameters 5 and 6 specify center frequency and span, in Hz.

The available frequency range depends on the instrument. Examples follow:

The stop frequency must be greater than the start frequency.

If parameter 3 specifies a single frequency point, parameter 4 can be cs or ss. Only parameter 5 is required (cent or start); parameter 6 would be parsed as a new command by the KC901.

7. Parameter 7:

Port1 -> Select input port 1 (PORT1).

Port2 -> Select input port 2 (PORT2).

8. Example:

When the number of acquisition points is greater than 1:

$spec,run,calon,lowlo,3,cs,100000000,50000000,port1\n
$start,spec\n
75000000,-110.573\n
100000000,-120.126\n
125000000,-113.269\n
$end\n

When the number of sweep points is 1:

SPEC performs repeated acquisition, with each acquisition returned in a separate packet, as shown below:

$spec,run,caloff,lowlo,1,cs,100000000,port1\n
$start,spec\n
100000000,-95.400\n
$end\n
$start,spec\n
100000000,-96.240\n
$end\n
$start,spec\n
100000000,-98.451\n
$end\n
$start,spec\n
100000000,-89.539\n
$end\n
