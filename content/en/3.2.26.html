3.2.26 S22 System Calibration (Fourth-Generation KC901X)

3.2.26 S22 System Calibration (Fourth-Generation KC901X) — reference table

Send command

Option

Description

cal_sys_s22

None

S22 system calibration

Description:

This command starts an interactive SOL calibration over the serial or Ethernet connection. The resulting calibration data is used by default in subsequent operation. Use the [Reset] command to restore factory calibration as the default. The procedure involves several exchanges. Host software only needs to identify packet header names; matching the message text is unnecessary.

$cal_sys_s22\n
$start,s22_SysCal_confirm\n
$******S22 System calibration******\n
$Do you want to calibrate the device?[Yes/no]\n
$end\n
$yes\n
$start,s22_syscal_wait\n
$ waiting for the circuit to be stability...\n
$end\n
$start,port_polarity\n
$Enter female or male to specify the polarity of the PORT2:\n
$end\n
$female\n
$start,cal_open\n
$Step 1:Please connect the OPEN module to PORT2 then send 'yes'.\n
$end\n
$yes\n
$start,cal_short\n
$Step 2:Please connect the SHORT module to PORT2 then send 'yes'.\n
$end\n
$yes\n
$start,cal_load\n
$Step 3:Please connect the LOAD module to PORT2 then send 'yes'.\n
$end\n
$start,cal_completed\n
$Calibration completed!\n
$end\n

While the instrument is waiting for confirmation from the host, the user can enter 'exit\n' to leave calibration mode, as shown below:

$exit\n
$start,exit\n
$Exit calibration\n
$end\n
