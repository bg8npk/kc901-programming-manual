Description:

1. Options:

init -> Initialize FIELD. Required before using FIELD.

run -> Run FIELD and acquire measurement data.

stop -> Stop and close FIELD. Required before switching to another operating mode.

2. Parameter 1:

lowlo -> Measure using the low local-oscillator setting.

highlo -> Measure using the high local-oscillator setting.

3. Parameter 2: Antenna gain, in dBi.

Antenna gain range: -100.00 to +100.00dBi.

Parameter 3: Single-point measurement frequency in Hz, with resolution down to 0.1Hz.

The available frequency range depends on the instrument, as shown in the following table:

5. Example:

Field strength is measured repeatedly, with each acquisition returned in a separate packet, for example:

$field,run,lowlo,10,100000000\n
$start,field\n
$100000000.0,-18.115,-121.917\n    ; Frequency, field strength, absolute level (dBm).
$end\n
$start,field\n
$100000000.0,-18.875,-122.337\n
$end\n
$start,field\n
$100000000.0,-18.667,-122.087\n
$end\n
