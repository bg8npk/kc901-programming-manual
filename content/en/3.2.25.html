3.2.25 S21 System Calibration (Fourth-Generation KC901X)

3.2.25 S21 System Calibration (Fourth-Generation KC901X) — reference table

Send command

Option

Description

cal_sys_s21

None

S21 system calibration

Description:

This command starts an interactive through calibration over the serial or Ethernet connection. The resulting calibration data is used by default in subsequent operation. Use the [Reset] command to restore factory calibration as the default. The procedure involves several exchanges. Host software only needs to identify packet header names; matching the message text is unnecessary.

This calibration can be performed only once after each initialization. To recalibrate, run $S21,STOP\n and initialize again with $S21,INIT\n.

The complete procedure follows:

$cal_sys_s21\n
$start,s21_SysCal_confirm\n
$******S21 System calibration******\n
$ Do you want to calibrate the device?[Yes/no]\n
$end\n
$yes\n
$start,s21_syscal_wait\n
$ waiting for the circuit to be stability...\n
$end\n
$start,port_polarity\n
$Enter female,male or f_m to specify the polarity of the PORTS:\n
$end\n
$female\n
$start,cal_connect\n
$Step 1:Please connect PORT1 and PORT2 then send 'yes'.\n
$end\n
$yes\n
$start,cal_completed\n
$Calibration completed!\n
$end\n

While the instrument is waiting for confirmation from the host, the user can enter 'exit\n' to leave calibration mode, as shown below:

$exit\n
$start,exit\n
$Exit calibration.\n
$end\n
