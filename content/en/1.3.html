1.3 Format Notes

1. Not every command requires options and parameters. Follow the relevant command table.

2. Square brackets [] are used only to describe placeholders in this manual. Do not type the brackets themselves.

3. Letters are case-insensitive unless stated otherwise.

4. If the contents of a command are invalid, the KC901 immediately returns an error message when it detects the error and discards the invalid packet.

5. If the command format is invalid, the KC901 discards incorrectly formatted portions and extracts only correctly formatted portions.
