Description:

1. Options:

init -> Initialize AfSource. Required before using AfSource.

run -> Run AfSource and output audio.

stop -> Stop and close AfSource. Required before switching to another operating mode.

2. Parameter 1:

off -> Disable modulation; parameters 4 and 5 need not be entered. [Source note: the parameter numbers are retained from the source; check the command table for this instrument generation.]

ask -> ASK modulation.

fm -> FM modulation.

pm -> PM modulation.

3. Parameter 2:

afout -> Select audio output (AF OUT).

port1 -> Select output port 1 (PORT 1).

port2 -> Select output port 2 (PORT 2).

3. Parameter 3:

Carrier frequency in Hz. Range: 0-2000000000Hz.

4. Parameter 4:

For output port "afout", amplitude is specified in mV peak-to-peak (VPP). Range: 0-3000mV.

For output port "port1" or "pot2" (spelled this way in the source), this parameter is the carrier output amplitude in dBm, with 1dB resolution.

The available output amplitude depends on frequency.

If the requested amplitude exceeds the available maximum, the instrument returns a warning and outputs the maximum amplitude.

$start,warn_gtr\n    ; Requested value exceeds the maximum.
$warn:It is greater than the maximum output!\n
$end\n

The source states that if the requested amplitude is below the available maximum, the instrument returns a warning and outputs the minimum. [Source note: "maximum" appears inconsistent with this lower-limit description; it has not been silently changed to "minimum".]

$start,warn_lt\n    ; The source comment says "requested value exceeds the maximum"; this conflicts with the lower-limit warning name.
$warn:It is less than the minimum output!\n
$end\n

For output port "port2", the approximate range is +10 to -81dBm.

For output port "port1" with RF board version "1.0.5" or later, the range is +10 to -111dBm. Otherwise, it remains +10 to -81dBm.

5. Parameter 5:

Modulation frequency in Hz.

For ASK, the range is 0-3000Hz.

For FM and PM, the range is 16-10000Hz.

6. Parameter 6:

Modulation depth / frequency deviation

For ASK, modulation depth ranges from 0 to 100%.

For FM, frequency deviation ranges from 0 to 1MHz.

For PM, the phase deviation ranges from -180° to +180°.

7. Example:

Configure the audio signal source for ASK modulation, a 10MHz carrier, 1.3V peak-to-peak (VPP) output, a 1KHz modulation frequency, and 100% modulation depth.

Step 1: Initialize AfSource:

$afsource,init\n

Step 2: Start operation and apply the settings:

$afsource,run,ask,afout,10000000,1300,1000,100\n

Step 3: Exit this mode before using another function.

$afsource,stop\n

8. Behavior:

(1) Init immediately initializes the circuits associated with the audio signal source.

(2) STOP immediately shuts down the circuits associated with the audio signal source.

(3) RUN starts output using the specified settings.

(4) While the source is outputting, other commands that do not explicitly require the source to stop leave the output running.
