3.2.27 S12 System Calibration (Fourth-Generation KC901X)

3.2.27 S12 System Calibration (Fourth-Generation KC901X) — reference table

Send command

Option

Description

cal_sys_s12

None

S12 system calibration

Description:

This command starts an interactive SOL calibration over the serial or Ethernet connection. The resulting calibration data is used by default in subsequent operation. Use the [Reset] command to restore factory calibration as the default. The procedure involves several exchanges. Host software only needs to identify packet header names; matching the message text is unnecessary.

$cal_sys_s12\n
$start,s12_SysCal_confirm\n
$******S12 System calibration******\n
$Do you want to calibrate the device?[Yes/no]\n
$end
$yes\n
$start,s12_syscal_wait\n
$ waiting for the circuit to be stability...\n
$end\n
$start,port_polarity\n
$Enter female,male or f_m to specify the polarity of the PORTS:\n
$end\n
$female\n
$start,cal_connect\n
$Step 1:Please connect PORT1 and PORT2 then send 'yes'.\n
$end\n
$yes\n
$start,cal_completed\n
$Calibration completed!\n
$end\n

While the instrument is waiting for confirmation from the host, the user can enter 'exit\n' to leave calibration mode, as shown below:

$exit\n
$start,exit\n
$Exit calibration\n
$end\n
