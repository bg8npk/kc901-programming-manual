2.2 Configuring Terminal Software

To simplify host programming, command echo is disabled and lines are terminated only by the newline character "\n". Terminal software may display the output incorrectly unless configured accordingly.

The source manual recommends SecureCRT to handle this behavior. Configure it as follows:

Select [View] -> [Command(Chat)Window] to open the command entry window at the bottom. Enter a command and press Enter to send it. Use the Up and Down arrow keys to recall previous commands.

Under [Options] -> [Session Options] -> [Terminal] -> [Emulation] -> [Modes], select [New Line Mode] so that "\n" is displayed as a carriage return followed by a line feed.
