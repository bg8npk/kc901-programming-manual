3.2.1 System Time

3.2.1 System Time — reference table

Command

Option

Description

date

get

Read the time.

set

Set the time using the following format:

Year Month Day Hour Minute Second

XXXX-XX-XX, XX-XX-XX

Example:

Read the KC901 system time:

$date,get\n
$start,date\n
Date:2025-12-30 15:22:14  ; Year, month, day, hour, minute, second, in that order.
$end\n

Set the time:

$date,set,2016-4-22,13-51-00\n

The year must be between 2000 and 2099.
