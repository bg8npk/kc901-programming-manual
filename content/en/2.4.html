2.4 Handshake with the KC901

Before the handshake, make sure that no dialog, such as About, is open on the KC901. If a dialog is open, the KC901 returns the following warning string. Fourth-generation KC901 instruments allow a handshake with a dialog open and do not return this warning.

$start,ConFail\n
$Please exit the window operation first.\n
$end\n

Close the dialog before attempting the handshake again.

Request control

Send an uppercase C.

After approximately 1 second, the instrument returns [KC901] and its serial number. The KC901 then enters remote-control mode.
