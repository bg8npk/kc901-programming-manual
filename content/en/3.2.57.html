3.2.57 Sweep Delay (Fourth-Generation KC901X)

3.2.57 Sweep Delay (Fourth-Generation KC901X) — reference table

Send command

Option

Parameter

Description

sweep_delay

get

set

Time

Add a sweep delay at each point (milliseconds).

Description:

The set option sets the delay at each point for both normal and frequency-list sweeps. Range: 0-10000ms.

The get option takes no parameters and returns the current delay setting.

This setting applies only to host-controlled operation and is separate from the instrument's local sweep delay setting. It resets to 0 when remote-control mode is exited. With a nonzero sweep delay, Sxx and spectrum modes can parse host commands while sweeping. The delay does not affect calibration sweep speed. It also does not affect single-point sweeps or zero-span operation with identical start and stop frequencies.

Example:

$sweep_delay,set,1000\n
$start,sweep_delay,set,success\n
$end\n
$sweep_delay,get\n
$start,sweep_delay,get,success\n
$1000\n
$end\n
