3.2.22 Remote Firmware Update (USB Serial Connection Only)

3.2.22 Remote Firmware Update (USB Serial Connection Only) — reference table

Send command

Option

Description

update

None

Update the firmware from the SD card.

Description:

Before sending this command, make sure the update files have been loaded onto the SD card. After receiving the command, the KC901 restarts automatically in remote update mode. Update progress messages are returned over the serial port and indicate success or failure. Fourth-generation KC901 instruments require a Boot version higher than 0.0.4 to support this command; it can be updated using the V1.5.6 base firmware update package.

Example:

$update\n

Note:

1. If an unexpected problem causes the instrument to freeze during a remote update, restart it to automatically retry the update.

2. During an update, the serial baud rate is fixed at 460800 on fourth-generation KC901X instruments and 921600 on third-generation KC901X instruments.
