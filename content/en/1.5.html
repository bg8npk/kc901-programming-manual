1.5 Communication Parameters

Baud rate: 921600 (third-generation KC901X)

Baud rate: 460800 (fourth-generation KC901X)

Data bits: 8

Stop bits: 1

Parity: none.

Command buffer: 32kb. Commands are executed in the order they enter the buffer. No new commands are accepted when the buffer is full. Allow for command execution time to avoid congestion.

Data buffer: 32kb. Data is transmitted in the order it enters the buffer. Execution is suspended when the buffer is full.

Measurement data obtained through remote control is not strictly rounded. Select the appropriate number of significant digits in your application.
