Description:

1. Options:

init -> Initialize S21. Required before using S21.

run -> Run an S21 frequency sweep and acquire data.

stop -> Stop and close S21. Required before switching to another operating mode.

2. Parameter 1:

caluser -> Not supported in remote-control mode on third-generation KC901X instruments.

calsys -> Enable system calibration.

caloff -> Disable system calibration.

3. Parameter 2:

ri -> Return real and imaginary components.

ma -> Return insertion loss and phase.

loss -> Return insertion loss (logarithmic value).

delay -> Return group delay.

4. Parameter 3:

lowlo -> Sweep using the low local-oscillator setting.

highlo -> Sweep using the high local-oscillator setting.

5. Parameter 4 sets the number of sweep points. Up to 1001 points are supported. For more points, use multiple commands to sweep separate segments. With 1 point selected, the instrument operates continuously.

6. Parameter 5:

cs -> Specify the sweep range using cent and span.

ss -> Specify the sweep range using start and stop.

If parameter 4 specifies a single frequency point, parameter 5 can be cs or ss. Only parameter 6 is required (cent or start); parameter 7 would be parsed as a new command by the KC901.

Parameters 6 and 7 specify frequencies in Hz. Use the format selected by parameter 5.

The available frequency range depends on the instrument, as shown in the following table:

The stop frequency must be greater than the start frequency.

If parameter 4 specifies a single frequency point, parameter 6 specifies that frequency and parameter 7 must be omitted.

8. Example:

When the number of acquisition points is greater than 1:

$s21,run,caloff,ri,lowlo,2,cs,100000000,50000000\n
$start,s21,ri\n
$75000000,-0.442e-1,0.000e0\n  ; Frequency, real component, imaginary component.
$100000000,-0.419e-1,0.174e-2\n
$125000000,-0.418e-1,0.219e-2\n
$end\n
$s21,run,caloff,ma,lowlo,2,cs,100000000,50000000\n
$start,s21,ma\n
$75000000,7.097e-1,180.000\n; Frequency, insertion loss, phase.
$100000000,6.758e0,157.210\n
$125000000,6.402e0,150.816\n
$end\n
$s21,run,caloff,loss,lowlo,2,cs,100000000,50000000
$start,s21,loss
$75000000,-116.130    ; Frequency, return loss (as labeled in the source).
$100000000,-102.054
$125000000,-112.225
$end
$s21,run,caloff,delay,lowlo,2,cs,100000000,50000000
$start,s21,delay
$75000000,-5.147039e-09
$100000000,2.589045e-09
$125000000,2.589045e-09
$end

When the number of sweep points is 1:

S21 performs repeated acquisition, with each acquisition returned in a separate packet, as shown below:

$s21,run,caloff,ma,lowlo,1,cs,100000000\n
$start,s21,ma\n
$100000000,6.744e-1,156.693\n
$end\n
$start,s21,ma\n
$100000000,6.766e0,156.762\n
$end\n
$start,s21,ma\n
$100000000,6.773e0,156.731\n
$end\n
