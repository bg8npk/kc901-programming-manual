3.2.55 S11 System Calibration (Third-Generation KC901X)

3.2.55 S11 System Calibration (Third-Generation KC901X) — reference table

Send command

Option

Description

cal_s11

None

S11 system calibration

Description:

This command starts an interactive SOL calibration over the serial or Ethernet connection. The resulting calibration data is used by default in subsequent operation. Use the [Reset] command to restore factory calibration as the default. The procedure involves several exchanges. Host software only needs to identify packet header names; matching the message text is unnecessary.

This calibration can be performed only once after each initialization. To recalibrate, run $S11,STOP\n and initialize again with $S11,INIT\n.

The complete procedure follows:

$cal_s11\n
$start,s11cal_confirm\n
$******S11 calibration******\n       ; Wait for the user to confirm calibration.
$ Do you want to calibrate the device?[Yes/no]\n
$end\n
$yes\n
$start,s11cal_wait\n                 ; Wait approximately 5 seconds for hardware warm-up. No data is returned during this time.
$ waiting for the circuit to be stability...\n
$end\n
$start,s11cal_step\n                 ; Follow the steps below.
$ start calibration, please follow these steps:\n
$end\n
$start,s11cal_short\n                ; Connect the short standard.
$Step 1:Please connect the short module then send 'yes'.\n
$end\n
$yes\n ; After confirmation, wait approximately 16 seconds for short calibration. No data is returned during this time.
$start,s11cal_open\n                ; Connect the open standard.
$Step 2:Please connect the open module then send 'yes'.\n
$end\n
$yes\n ; After confirmation, wait approximately 16 seconds for open calibration. No data is returned during this time.
$start,s11cal_load\n                ; Connect the load standard.
$Step 3:Please connect the load module then send 'yes'.\n
$end\n
$yes\n ; After confirmation, wait approximately 16 seconds for load calibration. No data is returned during this time.
$start,s11cal_process\n             ; Calculation in progress.
$Step 4: processing (Wait please).\n
$end\n
$start,s11cal_save\n                ; Saving.
$ saving(wait please) \n
$end\n
$start,s11cal_completed\n           ; Calibration complete.
$Calibration completed!\n
$end\n

While the instrument is waiting for confirmation from the host, the user can enter 'exit\n' to leave calibration mode, as shown below:

$exit\n
$start,s11cal_exit\n
$Exit calibration\n
$end\n
