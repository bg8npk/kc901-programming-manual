0. Overview

The KC901 communicates using text commands, commonly called ASCII commands. The physical connection uses the USB or Ethernet port. Inside the KC901, the data is converted to serial data for the CPU to process. You can operate the KC901 directly from a command line or write application software that communicates with the instrument using the commands in this manual.

The KC901 uses a simple, non-hierarchical command language. It can be learned quickly without studying complex protocol logic.

In this manual, the host is the PC or other controller used to operate the KC901. The instrument is the KC901.
