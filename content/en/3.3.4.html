Description:

1. Options:

init -> Initialize S12. Required before using S12.

run -> Run an S12 frequency sweep and acquire data.

stop -> Stop and close S12. Required before switching to another operating mode.

2. Parameter 1:

rescal -> Enable response calibration.

resisocal -> Enable response and isolation calibration.

enrescal -> Enable enhanced response calibration.

full2portcal -> Enable full two-port calibration.

syscal -> Enable system calibration.

caloff -> Disable system calibration.

3. Parameter 2:

ri -> Return real and imaginary components.

ma -> Return insertion loss and phase.

vswr -> Return voltage standing wave ratio.

series_z -> Return z, r, x for series impedance.

loss -> Return insertion loss (logarithmic value).

parallel_z -> Return z, r, x for parallel impedance.

4. Parameter 3:

lowlo -> Sweep using the low local-oscillator setting.

highlo -> Sweep using the high local-oscillator setting.

5. Parameter 4 sets the number of sweep points. Fourth-generation KC901 instruments support up to 10000 points; third-generation instruments support up to 1001 points. For more points, use multiple commands to sweep separate segments. With 1 point selected, the instrument operates continuously.

6. Parameter 5:

cs -> Specify the sweep range using cent and span.

ss -> Specify the sweep range using start and stop.

If parameter 4 specifies a single frequency point, parameter 5 can be cs or ss. Only parameter 6 is required (cent or start); parameter 7 would be parsed as a new command by the KC901.

7. Parameters 6 and 7 specify frequencies in Hz. Use the format selected by parameter 5.

The available frequency range depends on the instrument. Examples follow:

8. Example:

When the number of acquisition points is greater than 1:

$s12,run,caloff,ri,lowlo,3,cs,100000000,50000000\n
$start,s12,ri\n
75000000,0.0004,0.0000\n      ; Frequency, real component, imaginary component.
125000000,0.0006,-0.0000\n
$end\n
$s12,run,caloff,ma,lowlo,3,cs,100000000,50000000\n
$start,s12,ma\n
75000000,5.5840e+00,-80.8776\n ; Frequency, insertion loss, phase.
100000000,5.5576e+00,-99.7933\n
125000000,5.5032e+00,-120.9049\n
$end\n
$s12,run,caloff,vswr,lowlo,3,cs,100000000,50000000\n
$start,s12,vswr\n
75000000,-1.4405\n                ; Frequency, voltage standing wave ratio.
100000000,-1.4453\n
125000000,-1.4500\n
$end\n
$s12,run,caloff,series_z,lowlo,3,cs,100000000,50000000\n
$start,s12,series_z\n
75000000,25.3365,-24.9261,-4.5422\n ; Frequency, impedance magnitude, resistance, reactance.
100000000,23.9044,-23.5575,-4.0576\n
125000000,22.6288,-22.4014,-3.2002\n
$end
$s12,run,caloff,parallel_z,lowlo,3,cs,100000000,50000000\n
$start,s12,parallel_z\n
75000000,98.6349,-97.0458,17.6337\n ; Frequency, impedance magnitude, resistance, reactance.
100000000,104.4429,-102.9287,17.7202\n
125000000,110.3190,-109.2061,15.6306\n
$end
$s12,run,caloff,loss ,lowlo,3,cs,100000000,50000000\n
$start,s12,loss\n
75000000,-66.7922\n                 ; Frequency, return loss (as labeled in the source).
125000000,-71.9411\n
$end

When the number of sweep points is 1:

S12 performs repeated acquisition, with each acquisition returned in a separate packet, as shown below:

$s12,run,caloff,loss,lowlo,1,cs,100000000\n
$start,s12,loss\n
100000000,-62.0834\n
$end\n
$start,s12,loss\n
100000000,-57.5564\n
$end\n
$start,s12,loss\n
100000000,-56.5024\n
$end\n
$start,s12,loss\n
100000000,-56.5070\n
$end\n
