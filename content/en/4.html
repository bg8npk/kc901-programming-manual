4. Firmware Applicability

This manual applies to firmware V1.5.6 or later for KC901V/M, 1.2.9 or later for KC901C+/S+, 1.2.1 or later for KC901Q, and V1.5.6 or later for KC901J/K/R/T. Refer to an older manual for earlier firmware versions.

This manual does not list every functional difference between instrument models. Commands for a function that an instrument does not support are invalid. For example, KC901V does not support S22 measurement or full two-port calibration, so any command combination involving those functions is invalid.
