3.2.37 Reading System Warnings

3.2.37 Reading System Warnings — reference table

Send command

Option

Description

getstatus

None

Read system warnings.

Description:

If warnings exist, this command returns the system warnings once over the serial or Ethernet connection. If there are no warnings, no response is returned.

Example:

$getstatus\n
$start,err_BatVolLow
$error:Low battery!
$end
