Description:

Options:

init -> Initialize S11. Required before using S11.

run -> Run an S11 frequency sweep and acquire data.

stop -> Stop and close S11. Required before switching to another operating mode.

Parameter 1:

caluser -> Not supported in remote-control mode on third-generation KC901X instruments.

calsys -> Enable system calibration.

caloff -> Disable system calibration.

Third-generation KC901X instruments do not support user calibration in remote-control mode. Do not use caluser or the remote user calibration procedures previously listed in Sections 3.2.53 and 3.2.54. Any required user calibration algorithms must be implemented on the host.

Parameter 2:

ri -> Return real and imaginary components.

ma -> Return reflection coefficient magnitude and phase angle.

vswr -> Return voltage standing wave ratio.

z -> Return impedance.

loss -> Return return loss (logarithmic value).

Parameter 3 sets the number of sweep points. Up to 1001 points are supported. To sweep more than 1001 points, use multiple S11 commands to sweep separate segments.

A single measurement point is allowed. In this case, measurement continues and the instrument continuously sends results at that frequency to the host.

Parameter 4:

cs -> Specify the sweep range using cent and span.

ss -> Specify the sweep range using start and stop.

If parameter 3 specifies a single frequency point, parameter 4 can be cs or ss. Only parameter 5 is required (cent or start); parameter 6 would be parsed as a new command by the KC901.

Parameters 5 and 6 specify center frequency and span (cs), or start and stop frequencies (ss), in Hz. Use the format selected by parameter 4.

The available frequency range depends on the instrument, as shown in the following table:

7. Example:

When the number of sweep points is greater than 1:

$s11,run,caloff,ri,2,cs,100000000,50000000\n
$start,s11,ri\n
$75000000,0.528e0,-0.269e0\n  ; Frequency, real component, imaginary component.
$100000000,0.471e0,-0.406e0\n
$125000000,0.370e0,-0.475e0\n
$end\n
$s11,run,caloff,ma,2,cs,100000000,50000000\n
$start,s11,ma\n
$75000000,5.847e-2,-26.497\n ; Frequency, reflection coefficient magnitude, phase.
$100000000,6.171e-1,-40.609\n
$125000000,5.934e-2,-51.820\n
$end\n
$s11,run,caloff,vswr,2,cs,100000000,50000000\n
$start,s11,vswr\n
$75000000,3.7347\n   ; Frequency, voltage standing wave ratio.
$100000000,4.1275\n
$125000000,3.7658\n
$end\n
$s11,run,caloff,z,2,cs,100000000,50000000\n
$start,s11,z\n
$75000000,137.9871,109.6309,-83.7945\n   ; Frequency, impedance magnitude, resistance, reactance.
$100000000,113.8715,70.5131,-89.4127\n
$125000000,91.2070,52.7077,-74.4354\n
$end\n
$s11,run,caloff,loss,2,cs,100000000,50000000\n
$start,s11,loss\n
$75000000,-0.409\n; Frequency, return loss.
$100000000,-0.499\n
$125000000,-0.574\n
$end

When the number of sweep points is 1:

S11 performs repeated acquisition, with each acquisition returned in a separate packet, as shown below:

$s11,run,caloff,ri,1,cs,100000000\n
$start,s11,ri\n
$100000000,0.456e0,-0.391e0\n
$end\n
$start,s11,ri\n
$100000000,0.458e0,-0.392e0\n
$end\n
