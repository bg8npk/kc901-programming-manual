3.2.7 Barometer

3.2.7 Barometer — reference table

Command

Option

Parameter

Description

press

set

Value

Set the absolute altitude compensation in m. Range: -999.9 to 999.9.

After altitude compensation is set, the reported altitude changes gradually to the compensated value because a moving filter is used to stabilize the readings.

get

None

Read barometric data, returned in hPa and m, respectively.

Example:

Set altitude compensation to +100 meters.

$press,set,100.0\n

Read barometric measurement data with pressure in hectopascals.

$press,get\n
$start,press\n
$950.412,536.802\n  ; Pressure (hPa), then altitude (m).
$end\n
