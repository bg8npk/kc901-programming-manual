3.2.43 Frequency List (Fourth-Generation KC901X)

3.2.43 Frequency List (Fourth-Generation KC901X) — reference table

Command

Option

Parameter 1

freq_list

set

Frequency range

get

Description:

The set option sends a frequency list to the instrument in Hz. Separate frequencies with "-". After all frequencies have been received, the instrument returns "Frequency received successfully!".

The frequency list must contain at least 2 points and no more than 10000 points. The received list is stored in RAM and must be sent again after a power cycle. All frequencies must be within the instrument’s range. Repeating this command overwrites the previous list. Do not send an oversized list; whether the instrument rejects or truncates such a list remains to be confirmed.

Example:

$freq_list,set,100000000-200000000-40000000\n
$start,Frequency received successfully!
$end

The get option takes no parameters and returns the frequency list received by the instrument.

Example:

$freq_list,get\n
$start,freq
100000000
200000000
40000000
$end
