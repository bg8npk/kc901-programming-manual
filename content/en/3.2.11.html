3.2.11 S21 System Calibration Standard Parameters

3.2.11 S21 System Calibration Standard Parameters — reference table

Command

Option

Description

kit_s21

female

male

Enter the calibration standard length and attenuation, in that order.

Length range: 0-999.999 (mm)

Attenuation range: 0-99.9999 (dB)

Frequency at which attenuation is specified: 1-10000 (MHz)

Description:

Use female for female calibration standards and male for male calibration standards. Third-generation KC901X instruments do not have the female and male options.

Example:

Set the calibration standard length to 100.00mm and attenuation to 0.1dB at 4567MHz.

Fourth-generation KC901X example:

$kit_s21,female,100,0.1,4567\n

Third-generation KC901X example:

$kit_s21,100,0.1,4567\n
