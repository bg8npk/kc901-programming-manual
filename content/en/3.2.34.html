Description:

This command starts an interactive T+I calibration over the serial or Ethernet connection. When S12 response and isolation calibration is selected during subsequent operation, this calibration data is used by default. If the frequency range exceeds the calibrated range, system calibration is used instead. The procedure involves several exchanges. Host software only needs to identify packet header names; matching the message text is unnecessary.

$iso_response_s12_cal,10,cs,901000000,10000000\n
$start,s12_Cal_confirm\n
$******S12 Response+Isolation calibration******\n
$Do you want to calibrate the device?[Yes/no]\n
$end\n
$yes\n
$start,s12_response_isolation_cal_wait\n
$ waiting for the circuit to be stability...\n
$end\n
$start,port_polarity\n
$Enter female,male or f_m to specify the polarity of the PORTS:\n
$end\n
$female\n
$start,cal_load\n
$Step 1:Please connect the LOAD module to PORT2 then send 'yes'.\n
$end\n
$yes\n
$start,cal_connect\n
$Step 2:Please connect PORT1 and PORT2 then send 'yes'.\n
$end\n
$yes\n
$start,cal_completed\n
$Calibration completed!\n
$end\n

While the instrument is waiting for confirmation from the host, the user can enter 'exit\n' to leave calibration mode, as shown below:

$exit\n
$start,exit\n
$Exit calibration\n
$end\n
