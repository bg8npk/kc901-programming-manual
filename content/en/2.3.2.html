2.3.2 Configuring Network Parameters

Open IP SET under Settings and configure the KC901 IP parameters. Save the settings. The green Ethernet indicator flashes when the network connection is established.

DHCP: When enabled, the instrument obtains its IP address and gateway dynamically from the router. The source manual generally recommends disabling DHCP.

DHCP is supported only by fourth-generation KC901X instruments, not by third-generation KC901X instruments.

Port: The port number in the host software must match this setting. Avoid conflicts with other applications. If the host uses a firewall, allow traffic on the corresponding port.

IPv4 address: Choose an address within the permitted range of the connected network. It must not conflict with another device.

IPv4 gateway: Use the router's gateway setting. A common LAN default is 192.168.1.1.

IPv4 subnet mask: Set this according to the connected network; a common value is 255.255.255.0.

A network with a router is generally preferable. Both the KC901 and the host act as endpoints on that network. For a direct KC901-to-PC connection, assign different IP addresses on the same subnet to the PC and KC901. With some older network adapters, try a crossover Ethernet cable if the connection fails.
