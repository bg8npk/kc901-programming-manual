3.2.41 Power Sweep Settings (Fourth-Generation KC901X)

3.2.41 Power Sweep Settings (Fourth-Generation KC901X) — reference table

Send command

Option

Parameter

Description

power_sweep

get

set

start level

stop level

Operate the instrument in power sweep mode.

Description:

The set option takes the signal source start and stop amplitudes and places the instrument in power sweep mode.

The get option takes no parameters and returns the signal source start and stop amplitudes for power sweep mode.

Example:

$power_sweep,set,-50,10\n
$start,power_sweep,set,success\n
$end\n
$power_sweep,get\n
$start,power_sweep,get,success\n
$-50,$10\n
$end\n
