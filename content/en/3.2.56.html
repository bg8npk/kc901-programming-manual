3.2.56 S21 System Calibration (Third-Generation KC901X)

3.2.56 S21 System Calibration (Third-Generation KC901X) — reference table

Send command

Option

Description

cal_s21

None

S21 system calibration

Description:

This command starts an interactive through calibration over the serial or Ethernet connection. The resulting calibration data is used by default in subsequent operation. Use the [Reset] command to restore factory calibration as the default. The procedure involves several exchanges. Host software only needs to identify packet header names; matching the message text is unnecessary.

This calibration can be performed only once after each initialization. To recalibrate, run $S21,STOP\n and initialize again with $S21,INIT\n.

The complete procedure follows:

$cal_s21\n
$start,s21cal_confirm\n
$******S21 calibration******\n       ; Wait for the user to confirm calibration.
$ Do you want to calibrate the device?[Yes/no]\n
$end\n
$yes\n
$start,s21cal_wait\n                 ; Wait approximately 5 seconds for hardware warm-up. No data is returned during this time.
$ waiting for the circuit to be stability...\n
$end\n
$start,s21cal_step\n                 ; Follow the steps below.
$ start calibration, please follow these steps::\n
$end\n
$start,s21cal_connect\n                ; Connect PORT1 directly to PORT2.
$Step 1: Please connect [SOURCE] port and [RF IN] port then send 'yes'.\n
$end\n
$yes\n ; After confirmation, wait approximately 16 seconds for the calibration described as "short calibration" in the source. No data is returned during this time.
$start,s21cal_process\n             ; Calculation in progress.
$Step 3: processing (Wait please).\n
$end\n
$start,s21cal_save\n                ; Saving.
$ saving(wait please)\n
$end\n
$start,s21cal_completed\n           ; Calibration complete.
$Calibration completed!\n
$end\n

While the instrument is waiting for confirmation from the host, the user can enter 'exit\n' to leave calibration mode, as shown below:

$exit\n
$start,s21cal_exit\n
$Exit calibration.\n
$end\n
