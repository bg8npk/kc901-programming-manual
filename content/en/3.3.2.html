Description:

1. Options:

init -> Initialize S21. Required before using S21.

run -> Run an S21 frequency sweep and acquire data.

stop -> Stop and close S21. Required before switching to another operating mode.

2. Parameter 1:

rescal -> Enable response calibration.

resisocal -> Enable response and isolation calibration.

enrescal -> Enable enhanced response calibration.

full2portcal -> Enable full two-port calibration.

syscal -> Enable system calibration.

caloff -> Disable system calibration.

3. Parameter 2:

ri -> Return real and imaginary components.

ma -> Return insertion loss and phase.

vswr -> Return voltage standing wave ratio.

series_z -> Return z, r, x for series impedance.

loss -> Return insertion loss (logarithmic value).

parallel_z -> Return z, r, x for parallel impedance.

4. Parameter 3:

lowlo -> Sweep using the low local-oscillator setting.

highlo -> Sweep using the high local-oscillator setting.

5. Parameter 4 sets the number of sweep points. Fourth-generation KC901 instruments support up to 10000 points. For more points, use multiple commands to sweep separate segments. With 1 point selected, the instrument operates continuously.

6. Parameter 5:

cs -> Specify the sweep range using cent and span.

ss -> Specify the sweep range using start and stop.

If parameter 4 specifies a single frequency point, parameter 5 can be cs or ss. Only parameter 6 is required (cent or start); parameter 7 would be parsed as a new command by the KC901.

Parameters 6 and 7 specify frequencies in Hz. Use the format selected by parameter 5.

The available frequency range depends on the instrument. Examples follow:

The stop frequency must be greater than the start frequency.

If parameter 4 specifies a single frequency point, parameter 6 specifies that frequency and parameter 7 must be omitted.

8. Example:

When the number of acquisition points is greater than 1:

$s21,run,caloff,ri,lowlo,3,cs,100000000,50000000\n
$start,s21,ri\n
75000000,-0.4422e+00,5.2833e+00\n  ; Frequency, real component, imaginary component.
100000000,4.2138e-01,5.4467e+00\n
125000000,2.3253e+00,4.8666e+00\n
$end\n
$s21,run,caloff,ma,lowlo,3,cs,100000000,50000000\n
$start,s21,ma\n
75000000,5.4076e+00,105.4079\n; Frequency, insertion loss, phase.
100000000,5.4019e+00,85.9847\n
125000000,5.3388+00,64.8484\n
$end\n
$s21,run,caloff,vswr,lowlo,3,cs,100000000,50000000\n
$start,s21,vswr
75000000,-1.4390\n       ; Frequency, voltage standing wave ratio.
100000000,-1.4436\n
125000000,-1.4466\n
$end
$s21,run,caloff, series_z,lowlo,3,cs,100000000,50000000\n
$start,s21, series_z               ; Frequency, impedance magnitude, resistance, reactance.
75000000,105.6595,-104.1509,-17.7909\n
100000000,99.5815,-97.9082,-18.1789\n
125000000,92.8389,-91.3671,-16.4656\n
$end
$s21,run,caloff,parallel_z,lowlo,3,cs,100000000,50000000\n
$start,s21,parallel_z
75000000,23.5739,-23.2365,3.9740\n ; Frequency, impedance magnitude, resistance, reactance.
100000000,25.0008,-24.5743,4.5981\n
125000000,26.8217,-26.3855,4.8173\n
$end
$s21,run,caloff,loss,lowlo,3,cs,100000000,50000000\n
$start,s21,loss
75000000,-116.1302    ; Frequency, return loss (as labeled in the source).
100000000,-102.0541
125000000,-112.2253
$end

When the number of sweep points is 1:

S21 performs repeated acquisition, with each acquisition returned in a separate packet, as shown below:

$s21,run,caloff,loss,lowlo,1,cs,100000000\n
$start,s21,loss\n
100000000,-65.9755\n
$end\n
$start,s21,loss\n
100000000,-65.8623\n
$end\n
$start,s21,loss\n
100000000,-64.4023\n
$end\n
$start,s21,loss\n
100000000,-64.8623\n
$end\n
