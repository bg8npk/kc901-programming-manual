3.2.13 S21 User Calibration Standard Parameters (Fourth-Generation KC901X)

3.2.13 S21 User Calibration Standard Parameters (Fourth-Generation KC901X) — reference table

Command

Option

Description

userkit_s21

female

male

Enter the calibration standard length and attenuation, in that order.

Length range: 0-999.999 (mm)

Attenuation range: 0-99.9999 (dB)

Frequency at which attenuation is specified: 1-10000 (MHz)

Description:

Use female for female calibration standards and male for male calibration standards.

Example:

Set the calibration standard length to 100.00mm and attenuation to 0.1dB at 4567MHz.

$userkit_s21,female,100,0.1,4567\n
